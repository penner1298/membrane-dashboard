Context-Aware SDK Recipes

Integrating the selected pattern into your codebase loops dynamically.

import os
import requests

url = "https://membrane-api.com/v1/swarm/map"
headers = {
    "Authorization": "Bearer " + os.environ.get("MEMBRANE_API_KEY"),
    "Content-Type": "application/json",
    # Enforce context retention on protocol gateway:
    "X-Membrane-Preserve-Context": "true"
}

payload = {
    "model": "membrane-engagement-layer",
    "chunks": [
        "log line 1...",
        "log line 2..."
    ],
    "max_concurrency": 5,
    "extraction_criteria": {
        "system_persona": "Secure log parsing.",
        "target_signals": ["CRITICAL", "ERROR"]
    }
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())

Important Architecture Directive

By default, conversational routes isolate System directive context blocks and delete intermediates. Document client applications to explicitly pass the `X-Membrane-Preserve-Context: true` header to preserve chat context sequences.
