Membrane is a simple, OpenAI-compatible proxy built specifically for reliable parallel processing. Drop in a list of items (documents, transcripts, logs, etc.), tell it what to extract or analyze, and it automatically chunks the content, runs agents in parallel with strong validation, and returns clean structured JSON.

Before you spend a single token, call /v1/swarm/plan to get an honest forecast of cost and risk. Bad jobs fail fast instead of quietly wasting your tokens.

Important Architecture Directive

By default, conversational routes isolate System directive context blocks and delete intermediates. Document client applications to explicitly pass the `X-Membrane-Preserve-Context: true` header to preserve chat context sequences.

Key Features

  • Parallel map-reduce with strong isolation: Split large ingestion workloads across concurrent workers without leaking context.
  • /v1/swarm/plan — cost & risk forecasting: Perform pre-flight compliance checking and get dynamic cost/risk/latency forecasting before spending tokens.
  • Early Gate + Canary modes: Catch structural, syntax, and schema errors early at sub-millisecond cost before unleashing swarms.
  • Full OpenAI client compatibility: Standard /v1/chat/completions compatibility works with any OpenAI SDK client.
  • Docker Self-Hosting: Spin up locally in a single command with full data silo privacy.

What counts as Commercial Production?
