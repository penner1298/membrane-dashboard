# GitHub Descriptions & Short Copy

## Short Version (Recommended for GitHub repo description)

Membrane is an open-source proxy and parallel extraction engine for agent systems. It provides an OpenAI-compatible endpoint plus a specialized `/v1/swarm/map` primitive for processing arrays of text chunks concurrently with strong isolation between them.

Local use is free. Commercial production use is $29/month flat.

## Medium Version (Good for README header or docs intro)

Membrane is a self-hostable, open-source proxy and swarm extraction engine. It acts as an OpenAI-compatible gateway with multi-provider routing while offering a dedicated parallel map-reduce endpoint (`/v1/swarm/map`) designed for high-fidelity structured extraction from large documents and datasets through explicit chunk isolation.

Local development and testing is free. Commercial production deployments are $29 per month (flat fee, with annual discount available).
